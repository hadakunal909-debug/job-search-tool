🎯 Job-Search Tool — Architecture & Data Flow

Two scripts produce jobs.csv; the Streamlit app only reads it. No paid jobs API, no database.

flowchart TB

subgraph C["① COLLECT — scraper.py"]
  direction TB
  SRC["SOURCES: 26 verified company boards
(company, ats_type, url)"]
  API["ATS public JSON APIs
Greenhouse · Lever · Ashby · SmartRecruiters"]
  FILT["Filters
dedup by URL · entry-level title (INCLUDE/EXCLUDE)
· US location · H1B flag"]
  SRC --> API --> FILT
end

CSV[("jobs.csv
title, company, location, url, sponsors_h1b")]
FILT --> CSV

subgraph S["② SCORE — score_jobs.py"]
  direction TB
  GETJD["Fetch full job description
from the same ATS APIs"]
  SKILL["skill_match(resume, JD)
= % of the job's skills your resume covers"]
  GETJD --> SKILL
end
RESUME["resume.txt"] --> SKILL
CSV --> GETJD
SKILL --> CSV2[("jobs.csv + match_score")]

subgraph D["③ DISPLAY — app.py (Streamlit)"]
  direction TB
  FEED["Card feed
match ring · H1B badge · logo
sort: Best match · search/filter/tabs"]
  TAILOR["Tailor view (per job)
live JD · skill gaps · AI tailor · download"]
  FEED --> TAILOR
end
CSV2 --> FEED

subgraph SP["sponsor data (optional) — build_sponsors.py"]
  direction TB
  DOL["DOL H1B disclosure data (.xlsx)"] --> SPT["sponsors.txt"]
end
SPT -.-> FILT

YOU(["YOU
choose boards · edit resume · like / hide / apply"])
YOU -.-> SRC
YOU -.-> RESUME
YOU -.-> FEED

Solid arrows = data flow  ·  dashed = your inputs / optional. Run order: python scraper.py → python score_jobs.py → streamlit run app.py.

#
# PINNED, unlike everything above it. This library scrapes hostile targets, so its selectors and
# its output columns change whenever those sites change; an unpinned upgrade mid-run is a silent
# corpus problem, not a build failure. Re-pin deliberately after reading the changelog.
#
# NOT in requirements-cpanel.txt and must not be: it drags in pandas + numpy (~30 MB), which the
# web host has no use for. scraper.scrape_jobspy imports it lazily for exactly this reason —
# web.py imports the scraper module to serve /add, and that import must keep working without it.
#
# Installed but DORMANT: with JOBSPY_SITES unset, SOURCES holds no jobspy entries and the library
# is never imported. Installing it here rather than by hand is what makes enabling the feature one
# env var, instead of one env var plus a requirements edit that busts the pip cache.
